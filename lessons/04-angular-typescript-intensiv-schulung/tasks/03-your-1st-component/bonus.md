## ESLint - Static code analysis for your project
> Disclaimer: Please do this bonus task if you already have experience with **ESLint**.

- Open your project folder in a terminal
- Install angular-eslint executing the following command `ng add @angular-eslint/schematics`
- Execute `npm run lint` to check if everything is working.

Package Repository: [angular-eslint](https://github.com/angular-eslint/angular-eslint)
